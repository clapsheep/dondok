DONDOK / 돈독 — 1번 로고 벡터 파일
제작일: 2026-10-09

선택한 초록색 dondok 워드마크와 연결된 dd 아이콘을 벡터 윤곽으로 정리했습니다.
원본 시안의 비율과 실루엣을 바탕으로 곡선을 만들고, 미세한 이미지 질감은
단색 채우기로 정리했습니다.

파일 구성

1. dondok_logo_v1.ai
   워드마크와 앱 아이콘이 함께 들어 있는 Illustrator 7 호환 AI 벡터 문서입니다.
   여섯 글자, 아이콘 배경, dd 모노그램을 각각 이름이 있는 레이어로 분리했습니다.

2. dondok_wordmark.ai / dondok_wordmark.svg / dondok_wordmark.png
   영문 dondok 글자 로고만 담은 파일입니다.
   PNG는 너비 3000px이며 바깥 배경이 투명합니다.

3. dondok_app_icon.ai / dondok_app_icon.svg / dondok_app_icon.png
   연두색 둥근 배경과 초록색 dd가 함께 있는 앱 아이콘입니다.
   PNG는 1024 × 1024px이며 둥근 모서리 바깥이 투명합니다.

4. dondok_monogram.svg / dondok_monogram.png
   연두색 배경을 제외한 초록색 dd 심볼입니다.
   PNG는 너비 1024px이며 배경이 투명합니다.

5. dondok_logo_v1.svg
   전체 구성을 담은 RGB 벡터 원본입니다.
   Wordmark와 App Icon 그룹으로 나뉘며 각 글자를 따로 선택할 수 있습니다.

6. dondok_logo_preview.png
   흰 배경에서 전체 구성을 확인하는 미리보기입니다.

색상

짙은 초록: #19463C / RGB 25, 70, 60
연두:      #DBEE8B / RGB 219, 238, 139

두 색은 선택한 시안의 내부 픽셀 대표값을 기준으로 정리했습니다.

편집 안내

- AI와 SVG에는 이미지가 아닌 실제 벡터 경로가 들어 있습니다.
- 모든 글자는 윤곽선입니다. 폰트 설치가 필요 없으며 크기, 색, 윤곽을 편집할 수 있습니다.
- 글자 내용은 텍스트 입력 상자로 변경하는 구조가 아닙니다.
- 외부에 연결된 이미지, 폰트, 별도 플러그인이 필요하지 않습니다.
- Illustrator에서는 파일 > 열기로 파일을 열어 편집하는 용도입니다.

AI 형식과 검증 범위

AI 파일은 공개된 Illustrator 7 규격의 패스·레이어·RGB 색 연산자를 사용한
구형 호환 문서입니다. 최신 Adobe Illustrator 앱에서 직접 저장한 형식은 아닙니다.
PDF나 SVG 파일의 확장자만 AI로 변경한 파일도 아닙니다.

파일의 렌더링, 두 RGB 색상, 곡선, 내부 구멍, 바깥 배경의 투명성 및 대지 크기를
확인했습니다. Adobe Illustrator 앱에서 직접 열어 보는 검증은 수행하지 못했습니다.
함께 제공한 SVG는 동일한 도형을 가진 대체 벡터 원본입니다.

Illustrator에서 작업한 뒤 현재 사용 중인 버전의 AI 형식으로 다시 저장해
해당 버전의 문서 기능을 사용할 수 있습니다.
