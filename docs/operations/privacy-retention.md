# 휴면과 개인정보 보관 운영

2026-10-09 D-099. 사용자 위임에 따라 구현한 서비스 정책이며 모든 종류의 로그에 같은 법정 기간이 적용된다는 뜻은 아니다.

| 대상 | 적용 정책 |
| --- | --- |
| 회원 계정·공동 원장 | 마지막 인증된 이용으로부터 한국 달력 1년 후 휴면 표시. 정상 로그인 시 해제. 휴면 자체로 계정·공유 기록·명의를 삭제하거나 인증 조건을 완화하지 않음 |
| 기존 회원의 접속 이력 | 과거 이력이 없으므로 V40 배포 시각부터 추적. 가입일만 보고 즉시 휴면 전환하지 않음 |
| 이메일 인증·비밀번호 재설정 token | 사용 완료 또는 만료 후 매시 20분 정리. 유효한 token 유지 |
| 이메일 변경 인증 | 만료 후 같은 정리 작업으로 삭제. 아직 유효한 검증 결과 유지 |
| 미인증 회원 | 계정을 임의 삭제하지 않음. 1년 미이용 시 휴면 표시하며 이메일 인증 제한 유지 |
| 가입 동의 증거 | 계정 이용 기간 보관, 탈퇴 트랜잭션에서 삭제 |
| 일반 앱 진단 로그 | 운영 profile의 파일 로그, 당일과 이전 29개 날짜 범위, 최대 256MB. 시간마다 maintenance 로그를 기록해 유휴 시에도 일별 회전. 재시작 시 보관기간 초과 파일 정리 |
| 앱 nginx 요청 로그 | URL·IP·referrer를 저장하지 않음. production frontend/backend Docker 로그의 중복 영구 보관 비활성화 |
| 관리자 개인정보 업무 접속기록 | 별도 보존. 법정 최소 1년, 5만 명 이상·고유식별/민감정보 처리 등 조건이면 최소 2년. 일반 앱 로그 회전으로 삭제하지 않음 |
| 삭제 전 백업 | 기존 최대 30일 정책 유지. 암호화·만료·삭제 이력 재적용은 운영 호스트에서 별도 검증 |
| Resend Free | 업체 안내상 메일·로그 30일, 백업 7일. 계약 종료 후 잔여 데이터 최대 90일. 관리 화면에서 추적 기능 미활성화 확인 |

`V40`은 추가 열만 도입하며 금융 데이터나 과거 동의 증거를 수정하지 않는다. 휴면 전환과 활동 갱신은 동일 사용자 행의 원자적 UPDATE로 경합한다. 활동 기록은 인증된 credential hash 및 ACTIVE 상태를 다시 확인해 비밀번호 변경·탈퇴와 경합한 이전 세션이 계정을 복구하지 못하게 한다. profile version은 활동만으로 올리지 않는다. test profile은 정기 작업을 끄고 고정 시계로 경계·경합·token 정리를 검사한다.

공개 연락처는 호스트 `production.env`에 `DONDOK_LEGAL_OPERATOR_NAME`과 `DONDOK_LEGAL_CONTACT_EMAIL`로 설정한다. 이름·메일 원문은 사용자 답변과 Git 제외 배포 준비 설정에 보관한다. `.env.example`에는 가상 값만 둔다. 법정 문서 version은 `2026-10-09.1`이며 이전 원본을 보존한다. 발송 도메인의 관리 화면에서 추적 미활성화·도쿄 발송을 확인했고, 운영 DNS 조회는 프록시 비활성화를 확인했다. 저장 국가는 발송 리전과 별개로 Resend 공식 미국 보관 안내를 적용한다.

운영 backend의 `application-logs` volume은 서비스 사용자 전용 폴더다. `docker compose logs backend` 대신 이 volume의 파일을 제한된 운영 절차로 확인한다. 파일을 공개 CI artifact나 대화로 복사하지 않는다. Nginx Proxy Manager와 PostgreSQL 관리자 업무 기록은 이 앱 설정과 독립적이다. 해당 호스트의 실제 기록·접근권한·보존을 확인하기 전 운영 전체에 30일 삭제가 적용됐다고 주장하지 않는다.

## 근거

- [개인정보 보호법 제21조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334901): 목적 달성·기간 경과 후 지체 없는 파기, 법정 보존 예외의 분리 보관.
- [개인정보의 안전성 확보조치 기준 제8조](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000229672): 개인정보취급자의 업무 접속기록 최소 1년, 해당 조건에서 2년 및 점검. 일반 회원 진단 로그 30일은 서비스의 최소보관 정책이다.
- [개인정보보호위원회 유효기간제 폐지 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS212&mCode=C040030000&nttId=9579): 이번 휴면은 사용자 요청에 따른 서비스 정책이며 일률적인 법정 1년 삭제 의무로 설명하지 않는다.
- [Resend Security](https://www.resend.com/security), [DPA](https://www.resend.com/legal/dpa), [재수탁자](https://resend.com/legal/subprocessors): 요금제별 보관·미국 저장·계약 및 재수탁 내용. 저장 국가를 발송 region과 혼동하지 않는다.

2026-10-10 게시 준비 대조: 공개 연락처를 비공개 호스트 설정에 공급했다. Resend 관리 화면은 추적 기능 활성화 안내와 새 추적 도메인 생성 화면을 표시하며 기존 추적 설정이 없다. 외부 프록시 logrotate는 주 단위 4회/10회 보관을 사용한다. 이 프록시 기록을 앱 파일 로그 30일과 혼동하지 않는다. 실행 결과·호스트 식별자는 Git 제외 운영 증거로 보관한다.
