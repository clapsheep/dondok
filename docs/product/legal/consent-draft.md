# 가입 동의 구현 계약

D-087에 따라 구현한다. 공개 운영자·문의처는 Q-064에서 사용자 답변으로 확정했고 Git 제외 배포 준비 설정에 보관한다. Q-065의 보관·휴면 정책 결정은 완료했고 외부 설정 대조는 계속 진행한다. 이 구현은 App Store 승인 또는 법률 적합성을 보장하지 않는다.

## 사용자 흐름

- 가입 시 만 14세 이상, 이용약관, 개인정보 수집·이용 3개 항목은 모두 미선택이다.
- 전문 보기 버튼은 체크와 독립이다. 모달을 닫거나 회전해도 입력과 체크를 보존한다.
- `/legal/terms`, `/legal/privacy`는 로그인 없이 접근한다. 로그인·가입·설정에서 링크를 제공한다.
- 광고·마케팅 동의 및 법정대리인 흐름은 추가하지 않는다.
- 문서 조회 실패 시 재시도할 수 있고, 가입 요청은 문서 확인 후 가능하다. 오프라인 가입 큐는 만들지 않는다.

## 서버 계약

`GET /api/legal`은 `version`, `terms`, `privacy`, `collection`을 제공한다. 현재 원본은 `backend/src/main/resources/legal/2026-10-09.1/`이고 이전 버전을 보존한다. 공개 운영자·문의 이메일은 `DONDOK_LEGAL_OPERATOR_NAME`·`DONDOK_LEGAL_CONTACT_EMAIL`로 공급한다. 문서 변경은 새 버전을 발행하며 이전 버전 파일을 보존한다.

`POST /api/auth/sign-up`은 `consent: {version, age14OrOlder, termsAccepted, privacyAccepted}`를 요구한다. 누락/false는 400 `SIGNUP_CONSENT_REQUIRED`, 버전 변경은 409 `SIGNUP_CONSENT_VERSION_CHANGED`다. 버전 충돌 시 클라이언트는 필수 동의를 해제하고 문서를 다시 조회한다. 사용자의 재동의 없이 새 버전을 제출하지 않는다.

V37 `account_consent`에는 사용자별 문서 버전, 서버 동의 시각, 세 필수 확인을 가입과 같은 트랜잭션으로 기록한다. IP·생년월일은 추가 수집하지 않는다. 계정 삭제 시 함께 파기한다. 기존 회원에 대한 소급 동의는 조작하지 않는다.

## 출시 전 잔여 검토

공유 상대방 안내 및 개인정보 제공 근거, 외부 처리위탁·국외 이전 고지, 실제 보유기간과 문의처를 확정한 게시본을 새 버전으로 발행한다. 현재 처리방침은 준비 단계임을 명시한다. 공개 출시 시점에 Apple 공유 작성 콘텐츠 삭제 요구와 남은 원장의 재식별 가능성을 재검토한다.
