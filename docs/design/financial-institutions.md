# 금융기관·카드사 표시 자산 출처

돈독은 계좌·적금·대출·투자를 빠르게 식별하기 위해 금융기관 코드를 저장하고 작은 원형 아이콘으로 표시한다. 계좌·적금의 기관 목록은 금융결제원 CMS 참가기관 명칭, 대출의 캐피탈사 목록은 여신금융협회 리스·할부금융 회원사, 투자의 증권사 목록은 금융투자협회 회원사 명칭을 기준으로 정규화한다. 대출은 은행과 주요 캐피탈사를 함께 제공하고, 투자는 증권사만 제공한다. 기존 대출·투자는 기관을 추정하지 않고 `OTHER`로 이관한다.

로고는 각 기관의 공식 웹사이트가 직접 제공하는 favicon·브랜드 리소스만 32px 앱 자산으로 축소해 번들에 포함하며, 공식 소형 리소스가 확인되지 않은 기관은 기관별 색상과 약칭을 사용한다. 실행 중 외부 금융회사 사이트로 이미지 요청을 보내지 않는다. 같은 금융그룹의 확인된 심벌은 은행·증권·캐피탈의 원형 식별 표식에서 재사용할 수 있지만 화면의 기관명은 정확한 법인 브랜드로 구분한다.

신용카드·체크카드는 금융기관 코드와 분리된 카드사 코드를 사용한다. 정적 카탈로그는 `기타, KB국민, 신한, 삼성, 현대, 롯데, 우리, 하나, BC, NH농협` 순으로 제공한다. 은행 계열의 확인된 로컬 브랜드 이미지는 재사용하고, 별도 카드사 이미지를 번들에 넣지 않은 항목은 같은 크기의 브랜드 색상·약칭 badge로 표시한다. 카드사 표시는 자산 탐색 정보일 뿐 결제일·정산·posting 계산에는 영향을 주지 않는다.

## 공식 이미지 URL

이미지는 금융기관 식별 목적으로만 사용한다. 외부 이미지 요청 실패가 자산 탐색을 막지 않도록 항상 로컬 텍스트 fallback을 함께 렌더링한다.

카드사 카탈로그와 이미지도 앱 번들에서만 읽는다. 브라우저가 카드사 사이트나 제3자 CDN에 직접 요청하지 않으며, 공식 리소스 확인일과 출처가 바뀌면 이 문서와 정적 카탈로그를 함께 갱신한다.
