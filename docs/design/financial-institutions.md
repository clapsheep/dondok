# 자산 종류 아이콘 (D-093)

기관별 분류는 2026-10-09 사용자 결정으로 제거했다. 금융기관·카드사 선택과 로고를 제공하지 않는다.

`AssetIcon`이 기존 시스템 자산 종류에 따라 Lucide 아이콘을 표시한다. 현금은 지폐, 계좌는 계좌/은행, 카드는 카드, 적금은 저금통, 투자는 차트, 대출은 손/동전, 보험은 방패, 기타는 더보기 아이콘이다. 기본 20px이며 브랜드 색이나 이미지 배경을 사용하지 않는다.

V39에서 자산의 두 기관 코드 칼럼과 종속 제약·인덱스를 제거한다. 전용 기관 테이블은 없었다. 기존 자산 이름·종류·명의·잔액·원장·정산은 유지한다. 과거 migration은 checksum 보존용 이력으로 남긴다. 실행 카탈로그·로고·수집 manifest는 제거했다.
